## 三服真实会话移植

从本应用原有的独立 Mac 浏览器目录复制临时副本，按助手相同函数只导出必要字段，再在本机 Linux amd64 容器恢复。随后通过容器的任务 API 提交真实会话，在隔离 MySQL 中完成事务绑定、取分、重启与解绑；这些数据没有写回正式库。

| --- | --- | --- | --- | --- |
| Rin | currentAccount 中的 Token 字段 | 207 | 通过 | 通过 |
| MuNET | token、refreshToken、environmentKey | 317 | 通过 | 门户返回会话失效，正确提示重新登录 |
| 大饼 | TOKEN、ID_TOKEN、REFRESH_TOKEN | 126 | 通过 | 通过 |

大饼首次读取 357 条可用游玩历史，重启后解析新记录为 0，仍返回 126 条缓存成绩，未重新遍历全量。服务器每次核对绑定账号与主卡，不修改门户主卡。

MuNET 当前这份 refreshToken 无法续期，与之前实际门户会话行为一致；有效 accessToken 的跨系统恢复和同步已通过。失效后需要电脑助手完成官方登录/滑块，未尝试绕过验证码。

上述真实门户检查使用本机 Docker 的网络出口。腾讯服务器容器、新出口及最终 HTTPS 域名尚未部署验收；没有将本机验证描述成线上部署成功。HTTPS origin、Secure Cookie 和请求来源校验已在接口与编排测试中验证，最终域名证书与反代需按部署文档配置。
