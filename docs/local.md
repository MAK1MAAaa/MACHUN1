# 本机运行

MACHUN1 在本机提供单个工作台。网页和 API 只监听回环地址，打开网页即可操作。

## 安装与启动

使用 Node.js 24.x 和 pnpm 10.15.0。在项目根目录运行以下命令。

```bash
pnpm install --frozen-lockfile
pnpm browser:install
pnpm start
```

打开 [http://127.0.0.1:4399/](http://127.0.0.1:4399/)。首次启动时应用会创建 `.machun.local/machun1.sqlite` 并加载内置曲库。停止服务时，在启动终端按 **Ctrl+C**。

## 绑定成绩来源

展开「成绩来源」，点击 OTO（大饼）、Rin 或 MuNET 的「绑定账号」。配置完整的登录凭据后，工作台会在专用浏览器中填写并尝试提交一次。Rin 和 OTO 的常规 BEMANICN 登录授权也会自动确认。遇到 MuNET 滑块、额外权限、条款或验证码时，请在弹窗内处理。工作台随后识别身份并保存会话，之后点击「同步成绩」即可复用。落雪在工作台填写个人 API Token。[详细的来源操作](usage.md#sync)

## 可选配置

在项目根目录的 `.env` 中填写需要的配置，终端环境变量优先。修改后重启本机服务。请把包含密码的 `.env` 留在本机。[配置模板](../.env.example)

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `MACHUN_PORT` | `start` 为 4399，`preview` 为 4400 | 日常运行或预览时的访问端口 |
| `MACHUN_DATA_DIR` | `.machun.local` | 保存 SQLite、来源会话和旧版迁移副本。相对路径以项目根目录为基准 |
| `BCN_EMAIL` 和 `BCN_PASSWORD` | 空 | Rin 和 OTO（大饼）共用的 BEMANICN 登录邮箱与密码 |
| `MUNET_USERNAME` 和 `MUNET_PASSWORD` | 空 | MuNET 门户用户名与密码 |

密码包含 `#` 或首尾空格时，请用引号包住完整密码。凭据未配置时，可在弹窗中登录。

自定义位置建议使用项目目录之外的私有目录。默认的 `.machun.local/` 已排除在 Git 版本控制之外。

## 恢复旧成绩与备份

- **旧 MySQL 工作区**。在旧版界面导出完整备份，在新版「本地数据」中选择「导入备份」。完整备份会替换成绩和个人别名。来源需在本机重新绑定，导出昵称可在 BEST 30 重新设置。
- **旧版浏览器存储**。使用原浏览器打开原先的本机地址，工作台会尝试一次性导入旧成绩与别名，并保留原副本。
- **旧版本机绑定**。如果数据目录中已有早期版本的来源绑定 JSON，首次读取来源时会自动导入，并沿用同目录中的专用浏览器配置。

备份当前工作台的成绩与别名可直接使用「导出备份」。需要保留包括绑定和导出昵称在内的全部本地数据时，先停止服务，再复制整个数据目录。完整数据目录包含来源会话和 Token，请妥善保管。

## 开发与验证

```bash
pnpm dev
pnpm test
pnpm build
```

`pnpm dev` 的网页端口为 4399，API 端口为 4398。网页通过 Vite 代理访问 API。构建后可用 `pnpm preview` 在本机预览，默认端口为 4400。

如需用 Chromium 验证工作台与模拟门户流程，先执行 `pnpm browser:install`，再运行 `pnpm test:browser`。
