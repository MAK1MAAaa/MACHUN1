公网访问接受 IP 字面量及应用端口，Origin 必须同源，拒绝任意域名和伪造转发头。登录助手支持 `http://公网IP:1650`；绑定码仍隐藏输入、限时及一次提交。HTTP 网页的复制按钮增加选择复制兼容。HTTP 会明文传输网页登录请求和助手会话；可选 HTTPS origin 仍支持 Secure Cookie。

数据库连接由预设编排注入，镜像不包含数据库密码；`compose.yaml`、`.env`、个人目录和归档均排除镜像构建上下文。预设编排面向当前已初始化的 1Panel，不会自动创建另一份数据库。
